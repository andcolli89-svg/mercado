# CbOfertas V7.0
Base profissional preservando Início, Histórico, Cupons, Lote, Piloto, Configurações, exportação/importação e fotos por WebView local.

## Novidade estrutural
SQLite nativo com tabelas `offers`, `usage_history` e `saved_exports`.
A interface continua compatível com os dados antigos em localStorage durante a migração.
