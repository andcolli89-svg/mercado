LIMITAÇÃO HONESTA
A Alpha 5.3 aplica automaticamente links que já estão na Biblioteca de Afiliados. Um link afiliado novo não pode ser criado silenciosamente dentro da conta do Mercado Livre sem um fluxo oficial autenticado. Para um produto novo, o usuário abre o produto, gera o link uma vez, copia e toca em “Usar link copiado”. Nas próximas aparições do mesmo MLB, o preenchimento é automático.

COMPILAÇÃO DO APK
Este ambiente não contém o Android SDK/Gradle completo para gerar o APK local. O workflow incluído executa os testes Android e compila o APK real no GitHub Actions. Nenhum APK falso foi criado.
