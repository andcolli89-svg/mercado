# Escopo entregue

A V12 é um MVP completo e executável. Ela não inclui integração privada automática com o painel de afiliados do Mercado Livre, porque não há API pública documentada para essas métricas. Os dados entram por CSV/TXT e por rastreamento próprio.

Também não há disparo autônomo para grupos do WhatsApp. O aplicativo usa o compartilhamento oficial do Android e exige confirmação humana no WhatsApp Business.
