CBOFERTAS V6 ALPHA 5.2 — CONSULTA + LOTE WHATSAPP

NOVA ABA: LOTE WHATSAPP
- Cola vários anúncios copiados do WhatsApp.
- Remove data, hora, telefone e remetente adicionados pelo WhatsApp.
- Preserva parágrafos e converte \n literais em quebras reais.
- Separa automaticamente cada anúncio pelo link encontrado.
- Busca título, MLB e foto principal pelo backend já configurado.
- Reutiliza automaticamente o link afiliado salvo para o MLB.
- Botão Abrir ML para gerar/copiar um novo link afiliado.
- Botão Usar link copiado salva a associação para usos futuros.
- Compartilha foto + texto no WhatsApp Business.
- Depois de abrir o WhatsApp, o anúncio vai para Enviados e some dos Pendentes.
- A aba Enviados permite devolver o anúncio para Pendentes.
- Identificação e histórico ficam salvos localmente.

SISTEMA ANTIGO PRESERVADO
- Consulta individual por link.
- Radar.
- Histórico, favoritos, afiliados, cupons e agenda.
- Correção manual de parcelamento com/sem juros.
